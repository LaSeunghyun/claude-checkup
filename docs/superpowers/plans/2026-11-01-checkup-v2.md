# claude-checkup v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** v1(사용 현황 지도)을 검진 결과지 + 연결 지도 + 미리 보기가 있는 고치기 + 전후 비교로 바꾸고, 코드 리뷰의 보안 지적을 해소한다.

**Architecture:** 스캐너를 "기록 집계(느림, 캐시)"와 "분석(빠름, 순수)"으로 나누고, 분석은 가상 덮어쓰기(overlay)를 받아 미리 보기의 기대 효과를 같은 코드로 계산한다. 고치기는 새 `src/fix/` 모듈이 맡는다: 기계적 변경(플러그인 끄기, 보관 폴더로 옮기기)과 `claude -p` 임시 복사본 변경, 둘 다 미리 보기 → 백업 → 적용 → 되돌리기. 화면은 기존 React 앱에 결과지·연결 지도·고치기 시트를 더하고 v1 지도는 "사용 현황"으로 내린다.

**Tech Stack:** Bun 1.4, TypeScript(strict), React 19, Bun HTML 번들, `bun test`, Hearth DS CSS.

**Spec:** `docs/design.md` (v2). 시안은 `docs/mockups/`.

## Global Constraints

- 모든 한국어 문구·주석·문서는 하이픈 `-` 만 쓴다. em dash, en dash 금지 (테스트로 검사).
- 화면 어투는 해요체. "이(가)", "을(를)" 같은 기계식 조사 금지. 용어는 design.md 3절.
- 화면에 나가는 모든 글(본문, 요약, 개요, 훅 명령, 진단 문구, 요청문, diff)은 `redactSecrets` 를 거친다.
- 이름이 `isSecretName` 에 걸리는 파일은 열지 않는다. 비밀값이 든 파일은 `claude -p` 에 보내지 않는다.
- Claude 고치기가 쓸 수 있는 곳은 `HOME/.claude` 안, `HOME/.claude/plugins` 제외. 경로 기준 루트는 `HOME/.claude`.
- 앱이 쓰는 곳은 `HOME/.claude-checkup/`(cache, settings, history, backups, off, tmp)과 적용 시의 대상 파일뿐.
- `claude -p` 는 늘 `--no-session-persistence` 로 돌린다.
- UI 는 Hearth 토큰만 쓴다(hex·rgb·px 금지, 1px 보더와 도식 좌표·선 굵기 예외). 글자 13px 미만 금지, 라벨·버튼 15px, 히트 영역 44px, 화면당 `.btn-primary` 1개.
- 토큰 → A4 = 1,500 토큰/쪽, 화면에 "약". 컨텍스트 전체 200,000.
- `bun test` 와 `node_modules/.bin/tsc --noEmit -p .` 가 매 커밋 전 통과.

## Review Focus

1. 미리 보기를 만든 뒤 사용자가 Claude Code 에서 같은 파일을 고쳤다 → 적용은 거부되고 "파일이 그사이 바뀌었어요, 미리 보기를 다시 만들어 주세요"를 보여 준다 (Task 6 테스트).
2. 실행 파일 환경에서 `claude` 를 못 찾거나 로그인 안 됨 → 고치기 버튼이 "맡길 말 복사"로 바뀌고 앱은 계속 동작한다 (Task 7, 8 테스트).
3. `claude -p` 가 허용 밖 파일(대상 폴더 밖, 새 하위 폴더, 다른 메모리 폴더)을 고친다 → 그 변경은 버리고 미리 보기에 경고한다 (Task 7 테스트).
4. 적용 뒤 사용자가 그 파일을 다시 고쳤는데 되돌리기를 누른다 → 되돌리지 않고 백업 경로를 알려 준다 (Task 6 테스트).
5. MEMORY.md 가 없는 메모리 폴더(`~/.claude/memory`)와 `.claude` 가 아예 없는 홈 → 그래프·진단·결과지가 깨지지 않고, 폴더는 "목차 파일이 없는 폴더"로 설명된다 (Task 3, 9 테스트).
