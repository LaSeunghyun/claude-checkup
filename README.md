# Claude 설정 점검 (claude-checkup)

Claude Code에 쌓아 둔 설정(CLAUDE.md, 메모리, 작업 설명서, 에이전트, 자동 실행 규칙, 플러그인)이 실제로 어떻게 쓰이는지 점검하고, 미리 보기를 거쳐 고쳐 주는 앱이에요.

## 하는 일

- **검진 결과지**: 손볼 곳을 효과가 큰 순서로 3가지 보여 줘요. 고치면 무엇을 얻는지 함께 보여 줘요.
- **위험**: 메모리나 지시문에 토큰·키 같은 비밀값이 글자 그대로 적혀 있으면 알려 줘요. 값은 앱도 보여 주지 않아요.
- **연결 지도**: AI가 CLAUDE.md, MEMORY.md에서 출발해 어떤 md 파일까지 찾아갈 수 있는지, 길이 끊긴 파일은 무엇인지 보여 줘요.
- **고치기**: 고치기 전에 바뀌는 파일과 기대 효과(좋아지는 것과 치르는 것)를 먼저 보여 주고, 적용하면 백업해 둬요. 언제든 되돌릴 수 있어요.
- **전후 비교**: 다시 점검하면 지난번보다 무엇이 얼마나 바뀌었는지 보여 줘요.

## 실행

Windows는 `claude-checkup.exe`를 더블클릭하면 돼요. 브라우저가 열리고 점검이 시작돼요.
끄려면 열린 창(터미널)을 닫으면 돼요.

소스로 실행하려면 [Bun](https://bun.sh) 1.4 이상이 필요해요.

```bash
bun install
```

```bash
bun run start
```

## 보내는 것과 보내지 않는 것

- 점검은 전부 이 PC 안에서 해요. AI를 쓰지 않아서 사용량(토큰)도 들지 않아요.
- 이름에 credential, token, secret, auth 같은 말이 들어간 파일은 열지 않아요. 연결된 서비스(MCP)는 이름만 읽고 주소나 키는 읽지 않아요.
- **Claude로 고치기**를 쓸 때만, 고칠 파일의 복사본을 Claude에게 보내요. 평소 Claude Code를 쓸 때와 같은 방식이고, 처음 쓸 때 동의를 받아요.
  - Claude는 임시 복사본 폴더 안에서만 읽고 쓸 수 있어요(`--restricted`). 원본은 미리 보기를 확인하고 "적용하기"를 눌러야 바뀌어요.
  - 비밀값이 든 파일은 복사하지 않아요.
  - 한 번에 약 0.01~0.05달러가 Claude 사용량으로 들어요.
- 익명 사용 통계는 처음 실행할 때 동의한 경우에만 보내요. 파일 이름, 경로, 설정 내용은 보내지 않아요.

## 앱이 쓰는 곳

- `~/.claude-checkup/`: 점검 캐시, 설정, 점검 기록, 백업, 보관 폴더(`off/`), 임시 폴더
- 고치기를 적용할 때만 `~/.claude` 안의 대상 파일 (플러그인 폴더는 고치지 않아요)
